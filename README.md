# Calculadora

Calculadora web simples, com suporte a expressões complexas (parênteses,
porcentagem) e histórico de operações.

## Como usar

Abra o arquivo `index.html` em qualquer navegador — não precisa de instalação
nem servidor.

## Funcionalidades

- Operações básicas: soma, subtração, multiplicação e divisão.
- Parênteses para agrupar expressões (`( )`).
- Porcentagem (`%`).
- Suporte a teclado (dígitos, `+ - * /`, `Enter`, `Backspace`, `Escape`).
- Tema claro/escuro automático conforme o sistema.
